# 畫面行為

各頁面在操作與資料更新上的規則。導覽、選單、主題與變動串流等跨頁面的部分見 [App Shell 擴充點](app-shell-extension.md)；這裡只寫單一頁面的規則。

## 訂閱明細頁

### 收集設定的儲存

- 從選項中選的設定一選就送出。
- 輸入數字的欄位在停止輸入 600 ms 後才送出，逐位數打字只存一次；離開頁面時，還在等待的輸入立即送出。
- 欄位不接受的值不送出，留在畫面上等使用者修正；有尚未送出的設定時，「套用到同類」等到全部送出後才進行。
- 儲存一次送一個、依操作順序，較早的儲存不會蓋掉較晚的變更。
- 儲存進行中畫面顯示送出中的設定；儲存完成前回來的重新讀取仍帶舊設定，不取代畫面上送出中的值。

### 訂閱已被移除

讀取明細時訂閱已不存在（`subscription_not_found`）是一個答案：畫面顯示訂閱已不存在，並算作已跟上變動，不當成讀取失敗而持續落後。

## 文件頁與 Reader

- Reader 開啟中的文件有變動時，在原畫面重新讀取，不回到載入中；換到另一份文件時從載入中開始。
- 內文與「開啟原始內容」的連結以新視窗開啟；桌面版把 http(s) 新視窗交給系統瀏覽器，App 視窗不離開本機頁面。
- 確認刪除時文件已被其他視窗或 Agent 刪除（`document_deleted`），結果視同刪除成功。

## 記錄頁

- 換篩選條件就從頭讀取。原始事件的刷新把新的項目加在已載入的記錄上方，不重複。
- 摘要模式的刷新取代整份快照；使用者往前翻頁後，畫面固定在那份快照，直到換篩選、換模式或重新載入頁面，所以列與游標不會跨快照。
- 刷新不取消進行中的讀取：讀取期間來的變動在它結束後再讀一次，頻繁的進度更新不會讓記錄一直空著。
- 篩選的日期範圍在第一次載入時就固定，頁面開過午夜後「今天」仍指同一天，游標也維持有效。
- 依工作篩選時，工作已不再保存是一個答案：篩選照常顯示，算作已跟上；其他讀取失敗則等可以讀取時再讀。

## 設定頁

- 送到背景的知識庫切換在離開設定頁後繼續；回到設定頁時顯示它的結果。只有在送出之後讀到的狀態才能判斷它已結束。
- 新知識庫的資料夾名稱在停止輸入後才檢查，較新的輸入取消較舊的檢查；只有最新一次檢查說可以建立時才能按建立。
- Agent 連線的說明在滑鼠移上時顯示，也可以點擊釘住，讓鍵盤與觸控使用者閱讀；Escape 或點擊外面關閉。
