# 畫面行為

各頁面在操作與資料更新上的規則。導覽、選單、主題與變動串流等跨頁面的部分見 [App Shell 擴充點](app-shell-extension.md)；這裡只寫單一頁面的規則。

## 訂閱明細頁

### 收集設定的儲存

- 從選項中選的設定一選就送出。
- 輸入數字的欄位在離開欄位或按 Enter 時送出。
- 欄位不接受的值不送出，留在畫面上等使用者修正；有尚未送出的設定時，「套用到同類」停用。
- 儲存一次送一個、依操作順序，較早的儲存不會蓋掉較晚的變更。
- 儲存進行中畫面顯示送出中的設定，直到下一次讀到明細；這時讀到的是儲存前的設定時，畫面短暫顯示舊值，儲存完成後的重新讀取再顯示新值。

### 訂閱已被移除

讀取明細時訂閱已不存在（`subscription_not_found`），畫面顯示訂閱已不存在。

## 文件頁與 Reader

- Reader 開啟中的文件有變動時，在原畫面重新讀取，不回到載入中；換到另一份文件時從載入中開始。
- 內文與「開啟原始內容」的連結以新視窗開啟；桌面版把 http(s) 新視窗交給系統瀏覽器，App 視窗不離開本機頁面。
- 確認刪除時文件已被其他視窗或 Agent 刪除（`document_deleted`），結果視同刪除成功。

## 記錄頁

- 換篩選條件就從頭讀取。原始事件的刷新把新的項目加在已載入的記錄上方，不重複。
- 摘要模式的刷新取代第一頁；已載入的更早頁面中，比新第一頁最後一列更早的列留在下方，「載入更早的記錄」沿用它們的游標。摘要每次讀取都重新計算，翻頁期間新的定時檢查併入一組合併的檢查時，那一組可能在列表中少列或多列一次。
- 刷新不取消進行中的讀取：讀取期間來的變動在它結束後再讀一次，頻繁的進度更新不會讓記錄一直空著。
- 篩選的日期範圍在每次讀取時依當下時間計算。頁面開過午夜後，「今天」指新的一天；這時載入更早的記錄可能失敗，換一次篩選或重新整理頁面即可。
- 依工作篩選時，讀不到工作（例如已不再保存）只是不顯示工作的標題，篩選照常顯示記錄。

## 設定頁

- 建立或開啟知識庫的對話框停留到切換完成或失敗。Agent 開始的切換在設定頁顯示進度，期間建立與開啟的按鈕停用。
- 新知識庫的資料夾名稱在停止輸入後才檢查，只用來預覽將建立的位置或不能建立的原因，較新的輸入取消較舊的檢查。建立按鈕不等檢查結果；名稱或位置不能用時，伺服器拒絕；原因與預覽相同時只在預覽顯示一次，不同時另外顯示。
- Agent 連線的說明在滑鼠移上時顯示，也可以點擊釘住，讓鍵盤與觸控使用者閱讀；Escape 或點擊外面關閉。
