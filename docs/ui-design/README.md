# XR Collector UI Design Spec

本目錄的 HTML 是供各功能票開始開發的視覺 wireframe。#23 確認主要頁面用途、共用導覽、配色與基本版型；按鈕操作、進度、錯誤與其他狀態由各功能票開工時，連同功能及驗收計畫一起確認。後續設計調整隨功能票更新對應 HTML 與本說明，不必重新開啟 #23。產品需求與分工見 [Round 2 Plan](../round-2-plan.md)，wireframe 不代表已交付功能。

XR Collector 是 local-first 的資料收集與搜尋桌面工具。第一版支援 YouTube 影片字幕與頻道訂閱，架構上預留其他來源（RSS、網頁）的擴充空間。

執行環境：Electron desktop app，開發時用瀏覽器連到 Vite dev server 測試。業務邏輯在後端，前端只做呈現與操作觸發。

互動式 wireframe 畫布：https://claude.ai/artifact/FrdytTHRRBWzCpaSPVKcM7
（每個 artboard 的 Tweaks 面板可切換 dark / light 模式及各畫面狀態）

## 色系

採用 XQLab design system（位於 `~/projects/xqlab/design_system/`）的兩個主題：

- **Dark**：duskblue 暮藍（`:root` 預設）
- **Light**：silverblue 銀藍（`[data-theme="silverblue"]`）

XR Collector 是文件處理工具，排版比看盤畫面寬鬆，著重閱讀舒適度。

## 設計決策

### Onboarding（01-onboarding）

#20 的待確認方向：使用者先選目錄，再以單一按鈕顯示「建立知識庫」或「開啟知識庫」。以下雙按鈕描述與 HTML 保留為現有草圖，具體操作及畫面在 #20 開工時一起確認。

提供兩個獨立按鈕：「建立新知識庫」與「開啟既有知識庫」。使用者選擇目錄後，系統檢查目錄內容：

- **空目錄**：「開啟既有知識庫」按鈕淡化（opacity 0.35），引導使用者建立新庫。
- **偵測到既有知識庫**：卡片內出現藍色提示（文件數與訂閱數），兩個按鈕都可用。
- **路徑不可用**（State B）：紅色錯誤提示，顯示失敗路徑，使用者重新選擇目錄。
- **格式無法辨識**（State C）：黃色警告提示，說明可能原因，使用者選擇其他目錄。

路徑、權限與資料格式驗證成功後才進入主畫面；驗證失敗留在設定流程，不默默建立空庫。

### 收集來源（02-sources-youtube）

來源管理頁面用 tab 結構：YouTube / RSS / 網頁。第一版只有 YouTube tab 有功能，其他 tab 顯示為 disabled 狀態，展示介面的擴充性。

**YouTube URL 輸入**放在 YouTube tab 底下，單一按鈕依 URL 格式自動切換：

- 未輸入：按鈕顯示「加入」（灰化）
- 偵測為影片 URL：按鈕顯示「新增影片」
- 偵測為頻道 URL / @handle：按鈕顯示「訂閱頻道」

純播放清單 URL 本輪不支援，帶播放清單參數的影片 URL 按單支處理。

輸入框下方顯示功能說明文字：「貼上影片網址，將字幕內容加入知識庫。貼上頻道網址或 @handle，會擷取最新影片並自動定時追蹤新內容。自動收集的頻率與範圍可在**設定**中調整。」設定為 accent 色連結。

**Global 設定**集中於設定頁，來源頁不提供修改，只在功能說明中引導前往設定。預設每 30 分鐘檢查；首次及恢復補收最近 1 個月內最新最多 10 則未收集內容。

**頻道清單**：每列顯示 toggle（啟用/停用）、頻道名稱、文件數量、「暫停」按鈕（已暫停頻道顯示「已暫停」標籤）、垃圾桶圖示（移除訂閱）。不顯示 @handle（未必有），不提供單一頻道的「抓取」按鈕。

### 文件與搜尋（03-documents）

文件列表和搜尋合併在同一個畫面。頂部是搜尋欄（含清除按鈕）與單一來源下拉。來源下拉分組列出「全部來源」、每種來源的「全部」項目（目前為「YouTube（全部）」），以及該來源下的各頻道與篇數；不用 chip 排列，頻道多了不會撐爆。選單與篩選使用穩定的來源類型與頻道 ID，不以名稱比對。不在訂閱清單但仍有文件的頻道標示「未訂閱」，沒有頻道 ID 的舊文件歸在「未知頻道」並排在最後。其他來源類型加入時，在選單中新增自己的分組。

每列文件顯示：標題、正文節錄（2 行 clamp，正文開頭的純文字，非 AI 摘要）、來源標籤「YouTube · 頻道」、「發布 YYYY-MM-DD」與較淡的「收集 MM-DD」。沒有發布日期時顯示「發布日期未知」，不以收集日期代替。

- **瀏覽**：沒有查詢字串時依收集時間新到舊排列。列表與來源選單直接讀 Vault，不依賴搜尋引擎。
- **搜尋**：輸入後約 300ms 自動查詢，依關聯性排序，節錄改為命中片段並高亮命中詞，上方顯示「找到 N 份」。較晚送出的查詢一律優先，較早的回應不會覆蓋畫面。
- **分頁**：頁碼分頁，每頁 20 份，顯示總數。
- **狀態**：空 Vault 顯示「開始收集」按鈕並導向收集來源頁；搜尋沒有結果時顯示「沒有符合」；搜尋引擎無法使用時顯示警示列與「前往設定」，下方改列 Vault 文件，閱讀不受影響。
- **位置保留**：查詢、來源與頁碼放在網址（`/documents?q=&source=&page=`），捲動位置記在瀏覽紀錄；從 Reader 返回或重新整理都回到相同位置。

**文件刪除**（刪除功能交付後加入列與 Reader 的刪除圖示）：確認後刪除文件，Vault 保存刪除／略過記錄；後續排程與手動頻道批次抓取均略過。使用者明確以單支 URL 重新收集且保存成功後，才解除略過狀態；刪除文件不移除訂閱。

### 文件閱讀（04-reader）

Reader 的網址是 `/documents/<文件 ID>`，可重新整理或直接開啟；找不到文件時顯示「找不到這份文件」與返回按鈕。Sidebar 收合為 64px icon-only 模式，把最大空間留給閱讀區域；窄視窗時 Sidebar 回到頂部導覽。

閱讀排版參數：

- 內容寬度 720px，水平置中
- 正文字級 16px
- 行高 1.8
- 正文色 `textBody`（比 `textPrimary` 柔和，適合長文閱讀）

頂部是「返回文件列表」按鈕。Metadata 顯示來源標籤、標題（28px）、發布與收集日期、字幕語言與人工／自動字幕，以及原始網址；原始網址在系統瀏覽器開啟。正文以 Markdown 排版（標題、清單、強調、連結、表格），正文中的 HTML 以文字顯示，外部連結在系統瀏覽器開啟，遠端圖片不載入、改為連結。Reader 不標示搜尋命中。

### 設定（05-settings）

內容區域限制在 720px 寬，分成 7 個卡片區塊：

1. **知識庫 (Vault)**：顯示目前路徑、搬移按鈕
2. **匯出與匯入**：匯出 Vault、合併至目前知識庫、還原為另一份知識庫（匯入拆成兩個獨立操作）
3. **自動收集**：Global 設定——檢查頻率下拉（每 30 分鐘）、補收範圍兩個下拉（1 個月、10 則），附說明「所有訂閱共用此設定，修改後在下一次檢查時生效」
4. **搜尋索引**：狀態指示燈（就緒／啟動中／更新中／重建中／無法使用）、「已索引 N 份／知識庫 M 份」、上次重建時間、無法使用時的原因，以及「重建索引」按鈕；篇數不同時提示可重建
5. **啟動與常駐**：「登入電腦後自動啟動」toggle（預設關閉），說明啟用後背景啟動不開主視窗
6. **外觀**：深色/淺色主題切換
7. **關於與更新**：版本號、檢查更新按鈕、更新狀態（已是最新版 / 有新版 / 失敗）

### 活動記錄（06-activity）

上方顯示工作摘要與進度，下方為 Raw log viewer，等寬字體（`ui-monospace`），表格式三欄結構：

| 欄位 | 寬度 | 說明 |
|---|---|---|
| 時間 | 140px | `MM-DD HH:mm:ss` 格式 |
| 等級 | 60px | 色彩編碼的 level tag |
| 訊息 | flex | 操作描述 |

等級色彩：

- `INFO`：accent 藍（一般資訊）
- `OK`：statusGreen（成功新增）
- `DONE`：statusGreen（批次完成）
- `SKIP`：textTertiary 灰（已略過）
- `ERR`：statusError 紅（失敗）

提供時間、等級與工作篩選，以及載入更多；來源操作可直接跳到該工作的記錄。表頭 sticky，背景色與 log 區域一致。

後端寫 persistent log files，此畫面讀取並顯示。Agent API 也可以讀取 log 供使用者透過 Agent 查問題；Agent 可操作完整業務 API。活動記錄預設保留 30 天，工作接續資料另行保存。

### 桌面常駐與更新

關閉主視窗後隱藏至 Windows 系統匣／macOS 選單列，背景服務繼續收集；常駐入口顯示進度，提供開啟視窗、活動記錄及明確退出。登入自動啟動預設關閉，啟用後背景啟動、不開主視窗。

設定頁及常駐入口均提供手動檢查更新。自動檢查發現新版先通知；使用者明確觸發更新後才下載、安裝與重啟。

## 尺度

- 圓角：6px（輸入框、按鈕）、8px（卡片、面板）
- 間距：沿用 XQLab design system 的 `--p-*` 級距，但整體比看盤畫面寬鬆
- 頁面標題：22px, font-weight 600
- 卡片標題：14–16px, font-weight 500–600
- 正文：14px（列表）、16px（閱讀）
- 次要文字：12–13px
